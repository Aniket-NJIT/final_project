Developing this full stack FastAPI calculator has been a transformative learning experience that completely bridged the gap between backend architecture and frontend interactivity. The task of implementing Exponentiation and Modulus operations perfectly demonstrated the power of the Factory Design Pattern. Rather than rewriting core routing logic, I seamlessly integrated new operations by updating the backend factory, strictly enforcing Pydantic Enum validation, and connecting the frontend HTML UI.

However, the most significant challenges emerged during End to End testing. I encountered complex UI automation hurdles, including a Playwright race condition where the server state lagged behind the test execution, and a strict mode violation caused by duplicate "Edit" buttons populating the screen. The most insightful challenge was debugging a flaky test caused by unpredictable PostgreSQL database sorting after a row update. Overcoming this by utilizing highly specific Playwright locators—like .filter(has_text="...")—taught me exactly how to write resilient, bulletproof UI tests that do not rely on fragile list ordering. Furthermore, resolving underlying Linux dependency issues in the GitHub Actions pipeline solidified my understanding of CI/CD environments.

Going forward, my confidence in this modern tech stack is immense. I now feel fully equipped to architect secure, modular FastAPI backends with JWT authentication, design robust relational databases using SQLAlchemy, containerize applications with Docker, and confidently deploy fully automated, deeply tested microservices to production.
